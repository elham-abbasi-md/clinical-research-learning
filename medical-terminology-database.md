# English–Danish Medical Terminology Database

## Overview

This project aims to build a structured English–Danish medical terminology database using publicly available medical resources.

## Purpose

The goal is to improve medical terminology accessibility for healthcare professionals, students and internationally educated clinicians working in Denmark.

## Current Status

🟡 In Progress

## Objectives

- Build a structured bilingual medical terminology database
- Standardize medical terminology
- Improve terminology consistency
- Organize medical concepts into searchable datasets
- Apply data quality principles
- Document the entire development process
